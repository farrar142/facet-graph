# 오른쪽 메뉴 사람 확인 목록

메뉴는 창 위에 facet이 직접 그리므로 자동 테스트가 보지 못하는 부분이 있다. 오른쪽 메뉴(우클릭, Shift+F10, 메뉴 키)를
바꾸거나 Slint·입력 처리 코드를 바꿨으면 Windows 기계에서 아래를 직접 돈다. 메뉴 구성과 오른쪽 클릭의 선택 규칙은
`crates/facet-core/tests/menu.rs`가 확인한다.

## 열기

- [ ] 파일 행을 오른쪽 클릭: 메뉴가 클릭한 자리에 뜬다. 항목 순서는 열기, 새 탭에서 열기(꺼짐), 구분선, 잘라내기, 복사, 붙여넣기(꺼짐), 경로 복사, 구분선, 반대편 패널로 복사·이동, 복사 위치…, 이동 위치…, 구분선, 이름 바꾸기, 일괄 이름 바꾸기(항목 하나만 골랐으면 꺼짐), 삭제다(16줄).
- [ ] 폴더 행을 오른쪽 클릭: 「새 탭에서 열기」가 켜진다. 클립보드에 파일이 있으면 「붙여넣기」도 켜지고, 누르면 그 폴더 안에 붙는다.
- [ ] 선택 밖 행을 오른쪽 클릭: 선택이 그 행 하나로 바뀐다. 선택 안 행을 오른쪽 클릭: 선택이 그대로고 메뉴가 선택 전체에 적용된다(삭제 등).
- [ ] 목록 아래 빈 곳을 오른쪽 클릭: 선택이 풀리고 빈 곳 메뉴(뒤로, 앞으로, 위로, 구분선, 붙여넣기, 새 폴더, 실행취소, 구분선, 정렬 기준 ▶, 숨김 항목 보이기, 새로 고침, 구분선, 검색, 패널 나누기/합치기, 구분선, 경로 복사)가 뜬다.
- [ ] 패널이 둘일 때 비활성 패널을 오른쪽 클릭: 그 패널이 활성 패널(테두리·주소창 색)이 된다.
- [ ] 항목 옆에 단축키 글자(Ctrl+X, Ctrl+C, F2, Delete …)가 보이고 명령 팔레트의 글자와 같다.
- [ ] 빈 곳 메뉴의 뒤로·앞으로·위로·실행취소·검색·패널 나누기/합치기 줄 옆에 Backspace, Alt+→, Alt+↑, Ctrl+Z, Ctrl+F, Ctrl+\ 가 보이고 명령 팔레트의 첫 단축키 글자와 같다.
- [ ] 한 번 눌러 연 메뉴가 창 오른쪽·아래 끝 가까이에서도 창 밖으로 넘치지 않고 안쪽으로 옮겨 뜬다.
- [ ] 16줄짜리 빈 곳 메뉴가 창 아래 끝 가까이에서 열려도 창 밖으로 넘치지 않는다. ↑↓가 꺼진 줄과 구분선을 건너뛴다.
- [ ] 검색 결과 위치의 빈 곳 메뉴도 같은 순서이고, 뒤로를 누르면 검색한 폴더로 돌아간다.

## 빈 곳 메뉴의 새 줄

- [ ] 뒤로·앞으로·위로를 누르면 이동한다. 기록이 없는 새 탭에서는 뒤로·앞으로가 흐리고 눌러도 아무 일이 없으며, 드라이브 루트에서는 위로가 흐리다.
- [ ] 파일을 지운 뒤 빈 곳 메뉴의 실행취소를 누르면 상태 줄에 「〈작업 이름〉 실행취소」가 보이고 파일이 돌아온다. 작업 기록이 없으면 실행취소가 흐리다.
- [ ] 패널 나누기/합치기를 누르면 패널이 나뉘고(오른쪽 패널이 활성), 그 패널의 빈 곳에서 다시 누르면 합쳐진다.
- [ ] 검색을 누르면 활성 패널의 검색창이 열리고 포커스를 받는다.

## 꽉 찬 목록의 빈 곳

- [ ] `cargo xtask test-folder`의 10만 항목 폴더를 열고 목록 끝까지(End) 넘기면 마지막 행 아래에 한 행 높이의 빈 곳이 보인다. 그 빈 곳은 행이 아니라서 선택·커서에 들지 않는다(↑↓·End의 커서는 마지막 항목까지).
- [ ] 그 빈 곳을 오른쪽 클릭하면 선택이 풀리고 빈 곳 메뉴가 열리며, 새 줄(예: 위로)을 마우스로 누르면 실행된다.
- [ ] 그 빈 곳에서 왼쪽 버튼으로 끌면 사각형 선택이 된다. 끌며 목록 아래 끝 밖으로 나가면 끝까지 넘어가고 마지막 항목까지 골라진다.
- [ ] 다른 앱에서 끌어 온 파일을 그 빈 곳에 놓으면 현재 폴더로 들어간다(금지 커서가 아님).
- [ ] 폴더가 작아 목록이 꽉 차지 않을 때는 전처럼 마지막 행 아래가 빈 곳이다.

AC-12(빈 곳·항목 메뉴 구성이 선택 1만 개에서 `MENU_LIMIT` 10ms 안)는 사람이 확인하지 않는다. `cargo xtask ci`의 오른쪽 메뉴 구성 벤치마크(`facet-bench menu`)가 지킨다.

## 고르기

- [ ] 파일 셋 이상을 고르고 오른쪽 클릭: 「이름 바꾸기」 바로 아래 「일괄 이름 바꾸기」가 켜져 있고, 하나만 고르면 흐리다. 명령 팔레트에서 「일괄」로 찾아진다. 누르면 일괄 이름 바꾸기 창이 열린다(창의 확인 목록은 `specs/features/batch-rename/spec.md`의 AC-22·AC-23).
- [ ] 줄을 누르면 그 명령이 실행되고 메뉴가 닫힌다(복사 → 다른 폴더에서 붙여넣기, 삭제 → 휴지통, 이름 바꾸기 → 이름 입력란).
- [ ] 꺼진 줄은 흐리게 보이고, 마우스를 올려도 강조되지 않고, 눌러도 아무 일이 없다(메뉴는 그대로).
- [ ] 정렬 기준 줄에 마우스를 올리거나 → 를 누르면 하위 메뉴가 오른쪽에 열린다. 지금 정렬 기준에 ▲(오름차순)·▼(내림차순)이 붙는다. 같은 기준을 다시 고르면 방향이 뒤집힌다. 오른쪽에 자리가 없으면 왼쪽에 열린다.
- [ ] 숨김 항목 보이기가 켜져 있으면 ✓가 붙는다.
- [ ] ↑↓로 줄을 옮기면 꺼진 줄과 구분선을 건너뛰고 끝에서 반대편 끝으로 돈다. → 는 하위 메뉴 열기, ← 는 닫기, Enter는 실행, Esc는 메뉴 닫기다.
- [ ] 메뉴 밖을 누르면 닫히고(그 누름이 목록 항목을 고르지는 않는다), 닫힌 뒤 목록 키보드(↑↓ 등)가 다시 된다.

## 키보드로 열기

- [ ] 항목에 커서를 두고 Shift+F10: 커서 항목 바로 아래 옆에 항목 메뉴가 뜬다. 목록 맨 아래 항목이어도 창 안에 뜬다.
- [ ] 메뉴 키(Apps 키, 키보드에 있을 때)도 같다.
- [ ] 커서가 없는 빈 폴더에서 Shift+F10: 목록 왼쪽 위에 빈 곳 메뉴가 뜬다.
- [ ] 한글 입력기가 한글 모드여도 Shift+F10·메뉴 키가 같다.
- [ ] 이름 입력란·주소창에 입력 중일 때 Shift+F10은 facet 메뉴를 열지 않는다(입력란의 동작).
